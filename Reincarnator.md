# Isekai Reincarnator

Isekai reincarnator like Re:Zero, or maybe Groundhog Day

Mod saves the pawn outside of the save system. When you save scum you load the most recent version of the pawn with all the skills, traits, genes.

Scenario where you start with returns from previous campaigns.

## Check Compabilitity

- Isekai RPG Leveling (make sure these stats are saved)
- Vanilla Psycasts
